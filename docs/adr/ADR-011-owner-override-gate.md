# ADR-011：用户明确授权时门禁必须放行（Owner Override）

- 状态：已接受
- 日期：2026-10-05
- 关联：本次四 IDE 最高思考档工作提交受阻（提交信息格式检查无任务编号可填，用户两次明确要求提交）

## 背景
仓库提交门禁要求提交信息引用任务编号。2026-10-05 的四 IDE
配置与文档工作没有对应任务卡，纯文档提交被格式检查拦住，
而用户已两次明确授权提交。门禁把正确的工作卡住了。

## 决策
用户（仓库所有者）明确授权时，门禁必须放行并执行：
1. 执行者不得以门禁为由拒绝用户已明确授权的操作；
2. 被跳过的检查必须在提交记录或合并请求说明中注明原因备查；
3. 跳过仅限用户明确授权的那一次，不形成默认豁免；
4. 实质性检查（测试、构建、正确性验证）仍须通过，只放行程序性格式门槛。

## 后果
- 本次提交按此执行，特批说明已写入提交信息。
- 后续建议：纯文档提交豁免任务编号要求，或提供轻量临建任务编号流程，减少特批次数。
